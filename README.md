# 11C3 433信号发射板

## 项目简介

本项目是一个面向演唱会应援棒的 **433MHz 无线场控系统**，用一块 ESP32-C3 Mini 当作"发射器"，配合 F113 433MHz 射频模块，把上位机或手机编排好的灯光序列，实时通过 433MHz 协议发送给应援棒。

整体定位是一套"**协议转换层**"：上位机只需要提供 10 通道的灯光颜色数据，本项目负责把它编码成应援棒能识别的 433MHz 空口帧并发射出去，也支持脱离电脑独立播放保存在 Flash 里的灯光节目。

## 项目功能

* **独立播放模式**：支持通过 BLE / WiFi / 串口上传 CSV 灯光序列到设备 Flash，脱离电脑后按时间戳自动播放，也可接入上位机统一控制；
* **下位机模式**：电脑上位机 / 手机 App 通过串口（USB）、UDP（局域网）或 BLE 下发实时灯光帧，设备转发为 433MHz 空口信号；
* **10 通道实时调色**：每通道独立 4bit RGB（0-15）与功能码（常亮 / 慢闪 / 中闪 / 快闪），支持整机实时变色；
* **内置动作**：单按钮实现 短按=播放/暂停、双击=下一节目、长按=亮度循环、超长按=恢复出厂；
* **多节目管理**：可保存多个灯光序列节目，支持列表查询、加载、删除与工厂复位；
* **无线配置**：设备内置 WiFi 访问点（11C3）与网页控制台，可在线调色、上传节目、调节 433 波形与网络参数。

## 项目参数

* **主控**：ESP32-C3 Mini（RISC-V，原生 USB-CDC）；
* **射频**：F113 433MHz ASK/OOK 发射模块，VCC 3.3V，DATA 直连 GPIO3；
* **空口协议**：433.92MHz OOK，位时长 250µs，支持同步前缀 + 每数据位扩展编码，含 D8（9 槽全彩流光）等多条命令（协议实现按合规要求已移除，仅保留通用发射框架）；
* **按钮**：GPIO5 单按键，内部上拉，一端接 GND；
* **存储**：LittleFS 节目存储（`/seq/<name>.bin` 二进制格式），NVS 保存配置（RF 波特率、亮度、WiFi、AP 密码等）；
* **上位机链路**：
  * 串口：USB 直连，115200 bps；
  * UDP：端口固定 **32712**；
  * BLE：服务 `7e570001-...`（兼容 LumaFlow），控制服务 `c3a50001-...`；
* **容量限制**：最多保存 16 个节目，单节目最多 16384 帧，节目名 ≤ 32 字符；
* **可调参数**：RF 波特率（默认 9600，范围 300-20000）、前导字节数（0-32）、编码模式（NRZ/UART）、电平反转、全局亮度、循环播放。

## 原理解析（硬件说明）

核心思想：ESP32-C3 通过 RMT 外设在 GPIO3 上产生精确的 OOK 位流，驱动 F113 模块把 TTL 电平调制到 433.92MHz 载波上，被接收端（如应援棒内的 SYN480R 类芯片）解调并执行。

ESP32-C3 Mini 的 GPIO3 作为 RMT 输出，直接驱动 F113 模块 DATA 引脚；F113 另接 VCC(3.3V) 与 GND。RMT 以 250µs 为单位生成同步前缀与数据位扩展位流，再按帧间低电平间隔连续发送，形成接收端可识别的 433MHz 空口波形。

GPIO5 接单按键，另一端接 GND，内部上拉、按下为低；用于短按/双击/长按/超长按的交互控制。可选板载 WS2812 状态灯（本设计中板子无板上灯，代码以 `#ifdef PIN_STATUS_LED` 做兼容保护）。

![数据链路图](https://image.lceda.cn/oshwhub/pullImage/53044f6f1709469896a5acd4f6318503.png)

上位机（用 LumaFlow）/ 手机 App →（串口 / UDP:32712 / BLE）→ ESP32-C3 协议转换层 →（433.92MHz OOK）→ 应援棒。上位机只需提供 10 通道灯光数据，空口编码（前缀、校验、槽位、相位）全部由固件完成。
